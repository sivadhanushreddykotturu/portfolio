The original design and foundation for this portfolio were created by my junior, **Deepthanush Chowdary**. You can check out his original repository here: [Deepthanush1337/dev-portfolio](https://github.com/Deepthanush1337/dev-portfolio).

## Features

- **Responsive Design**: Mobile-first architecture built with Tailwind CSS.
- **Dynamic Profile**: Live age counter with millisecond precision.
- **GitHub Integration**: Automatically fetches and merges open-source repositories and contribution heatmaps from both of my GitHub accounts (`@sivadhanushreddykotturu` and `@scavengerui`).
- **Dark/Light Theme**: Built-in toggle with persistent `localStorage` preference.
- **Skill Filtering**: Interactive tags to filter skills by categories.

## Tech Stack

- HTML5, CSS3, JavaScript (vanilla)
- Tailwind CSS (CDN)
- Simple Icons & Devicon (CDN)
- Vercel (Ready for deployment)

## Local Development

You can run this project locally using any simple HTTP server. For example, with Python:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080` in your browser.

## Deployment

Since this is a purely static site with client-side API fetching, it can be easily deployed to Vercel, GitHub Pages, or Netlify with zero configuration.

For Vercel:
1. Push this repository to GitHub.
2. Import the project in Vercel.
3. Click "Deploy" (no build commands necessary).
